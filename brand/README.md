## Prompt record

The light lockup prompt preserved the approved DCC-MCP master and replaced the
earlier chip motif with one protocol ribbon branching into four neutral agent
runtime ports. It required the exact footer
`DIGITAL CONTENT CREATION | AGENT PLUGINS | MODEL CONTEXT PROTOCOL`, the shared
navy/blue/cyan palette, a teal project motif, a white background, and no vendor
logos, badges, cards, robots, puzzle pieces, extra labels, or watermark.

The dark lockup prompt changed only theme and contrast, using the approved dark
master treatment on `#081426` while preserving layout, four endpoints, footer,
and project colors.

The icon prompt extracted the protocol hexagon, pixel origin, and four-port
branch into a square, text-free composer icon with a strong 32 px silhouette.
